# Power BI Dashboard
This folder contains the interactive Power BI dashboard developed as part of the **Apple Sales Analytics** project.

## Apple Sales Dashboard
The dashboard provides an interactive analysis of Apple sales performance across different years, countries, product categories, sales channels, customer segments, payment methods, and return statuses.

### Key Features
- **Key Performance Indicators**
  - Total Orders
  - Total Units Sold
  - Total Revenue
  - Average Sales Order Value
- **Interactive Slicers**
  - Year
  - Country
  - Category
- **Sales Analysis**
  - Revenue trends by Year and Quarter
  - Revenue by Country
  - Revenue by Product Category
  - Revenue by Sales Channel and Customer Segment
  - Revenue by Payment Method and Customer Age Group
  - Units Sold by Return Status
- **Interactive Visualizations**
  - Trend analysis
  - Category-wise sales analysis
  - Country-wise revenue comparison
  - Sales channel analysis
  - Customer segmentation
  - Return status analysis


The dashboard was developed using the cleaned and updated dataset prepared during the Excel data-preprocessing stage.
