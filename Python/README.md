# Python Analysis
This folder contains the Python-based data analysis performed as part of the **Apple Sales Analytics** project.

## File

### Apple_Sales_Analysis.py

This Python script contains the data analysis and exploratory data analysis performed on the Apple Sales dataset.

The analysis includes:

- Loading and inspecting the dataset
- Data cleaning and preprocessing
- Handling missing values and duplicate records
- Data type validation
- Exploratory data analysis
- Statistical summaries
- Sales and revenue analysis
- Group-wise analysis using Pandas
- Data visualization using Matplotlib

## Libraries Used

- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical computations
- **Matplotlib** – Data visualization

## Workflow

The Python analysis is performed after the initial data cleaning and preparation in Excel. The insights generated through Python complement the SQL analysis and Power BI dashboard developed as part of the project.
